# Portable X01 teaching fixture

`common_mesh/` contains the exact shared X01 geometry and physical settings in
the three exchange formats used by the experiment:

- MAT for PyEIDORS and EIDORS;
- Gmsh 2.2 MSH for NGSolve;
- JSON metadata and fingerprints.

`exact_reference.json` contains fraction strings over `QQ` for:

- the exact electrode-voltage matrix;
- the exact rational reduced map;
- the exact rational reduced right-hand side;
- the Classic-zero-residual, Robin-zero-residual, voltage-identity, and gauge
  certifications.

It is a portable teaching reference. The authoritative full-suite truth is
regenerated by `scripts/benchmarks/cem_exact_extension_suite.py compare`.
